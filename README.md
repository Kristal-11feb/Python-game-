# Python-game-
🎮 My Awesome Escape Room Game! 
🚪💰Hi! Welcome to my very first Python game! I made an adventure game where you have to escape a room by collecting cash and solving puzzles.
🚀 How to Play
Make sure you have Python installed on your computer.Download or copy my code into a file called game.py.
Open your terminal or command prompt and run it:python game.py
Type your name and follow the on-screen instructions by typing numbers (1, 2, 3, or 4) to move around and make choices!
🗺️ What's Inside the Game?Main Hall: 
The starting room. Choose to go to the Out Door or the Chamber.Chamber: Where all the fun stuff is!Open a secret chest to get 3 cash right away! 
🎁Answer a GK Question about Nepal to earn cash.
Solve a Jumbled Word puzzle to get more cash.
Out Door: The final exit! You need at least 5 cash to open the door and win the game! ☀️
